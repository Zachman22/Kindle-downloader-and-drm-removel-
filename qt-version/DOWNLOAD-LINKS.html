📦 Download Qt WebEngine

Qt WebEngine is required to build the Kindle DRM Converter. It's used for Amazon login and downloading your Kindle books.

⚠️ Important: During Qt installation, you MUST check the "Qt WebEngine" component under "Additional Libraries"!

🚀 Quick Download

⬇️ Download Qt Online Installer
File: Qt Online Installer for Windows (~30 MB)
Full Installation Size: ~4-6 GB
Installation Time: 30-60 minutes

📋 Installation Steps

Step 1: Download and run the Qt Online Installer (link above)
Step 2: Create or sign in to your Qt account (free)
Step 3: When selecting components, CHECK these:
  • ✅ Qt 6.7.0 (or latest 6.x version)
  • ✅ MinGW 11.2.0 64-bit
  • ✅ Additional Libraries → Qt WebEngine ⚠️ MUST HAVE!
  • ✅ CMake 64-bit
  • ✅ Qt Creator (optional but recommended)
Step 4: Click Install and wait for completion (30-60 min)
Step 5: After installation, verify Qt WebEngine is installed:
  • Check folder exists: C:\Qt\6.7.0\mingw_64\lib\cmake\Qt6WebEngine
  • Or run: check-qt-webengine.bat

✅ After Installation

Once Qt (with WebEngine) is installed:
  1. Open Command Prompt
  2. Navigate to: qt-version folder
  3. Run: start-here.bat
  4. Follow the automated build process

🆘 Need Help?

If you already have Qt installed but missing WebEngine:

  1. Run: C:\Qt\MaintenanceTool.exe
  2. Select "Add or remove components"
  3. Navigate to Qt → Additional Libraries
  4. Check "Qt WebEngine"
  5. Click Update

📚 Documentation

See these files in the qt-version folder:

  • INSTALL_QT_WEBENGINE.txt - Detailed installation guide
  • check-qt-webengine.bat - Check if WebEngine is installed
  • start-here.bat - Automated build script
  • BUILD_WINDOWS_EXE.md - Complete build documentation
